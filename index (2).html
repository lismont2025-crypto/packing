Import Excel (.xlsx)

Reads sheet headers, rows and values from an existing workbook and maps them into the editable report below. Values, not screenshots — every cell can be edited afterward.

Import PDF

Extracts text/table content from a text-based PDF (e.g. one exported by this app) into editable rows. Scanned/photographed PDFs need OCR, which requires a server-side OCR service — not something a browser-only page can do reliably; the extracted text box below will show raw lines for you to map manually in that case.
